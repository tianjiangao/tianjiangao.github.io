# Gao Eric Tianjian · 高天健

Personal website: https://tianjiangao.github.io/

This repository hosts the pre-rendered React frontend on GitHub Pages. Chinese/English views, dark mode, résumé downloads, the scroll viewer, and the contact form work here. Contact submissions are stored by the existing Sites backend; the owner inbox requires sign-in.

The included website-source.zip contains the frontend source and assets. To rebuild, extract it, install Node.js 22+, run npm install, then npm run build:pages. Publish the contents of dist-pages to this repository's main branch. Deployment uses GitHub Pages from main / root.
